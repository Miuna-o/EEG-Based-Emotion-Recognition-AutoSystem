# 心澜桌面应用

脑电支持的心理健康辅助筛查与状态评估。Windows 独立应用窗口，保留原 React/TypeScript 界面设计，内置 WebView2 宿主自动管理 FastAPI/SQLite 本地服务。

**日常使用**按[本机启动说明](../../../AGENTS.md#在本机启动)打开「心澜」桌面窗口，应用会自动启动本地服务。操作步骤和练习文件见[心澜完整使用手册](../../../心澜_完整使用手册.md)。
