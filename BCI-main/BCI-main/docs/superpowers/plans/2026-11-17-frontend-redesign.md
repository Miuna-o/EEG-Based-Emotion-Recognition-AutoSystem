# 心澜前端升级实施计划

> 子任务按 superpowers:subagent-driven-development 执行。

**目标**　将已确认的首页样稿推广到心澜的所有 React 页面，交付离线可用的字体、共享组件和真实摄影。

**设计依据**　2026-11-17 会话确认的首页样稿与前端升级方案。

**架构**　保留现有路由、同源服务和数据契约。Mantine 提供交互组件，Lucide 提供图标，ECharts 渲染波形。各业务页通过现有接口提交数据。

## 实施顺序

- [x] 把现有浏览器用例的首页预期更新为样稿标题，并在改造前运行确认差异。补充生产同源用例，验证首页及各摄影页面由同源加载图片。
- [x] 更新应用壳、首页、共享组件、字标、字体、摄影和主题。主题使用暖白、墨青、深青绿，状态颜色附文字。摄影与字体使用本地构建资源，并记录来源与授权。
- [x] 更新导入与波形界面。步骤覆盖数据来源、导入、元信息与预览、保存或提交。复用当前校验、草稿、版本与幂等行为。
- [x] 更新任务、结果与记录。强化状态、日志、来源版本、复核及报告操作。维持历史绑定与过期报告预览关闭行为。
- [x] 更新研究工具、设置帮助及文字助手。保留设备、服务与研究工具的实际能力说明。
- [x] 在临时数据环境执行完整合成演示和生产同源测试，检查键盘操作、窄窗口、图标与文字对比度，构建桌面应用使用的静态资源。

## 回归重点

- 真实与演示入口、任务来源与标签一致，真实模式可以保存草稿。
- 元信息文本输入、异常和提交重试的幂等键使用既有验证。
- 历史记录继续使用绑定版本，过期预览按既有规则关闭。
- 支持桌面最小窗口、等效缩放与 Tab 操作。
- 照片与字体从生产静态资源加载，核心操作可离线执行。
