# 功能覆盖与已知边界

| 能力 | 当前状态 |
|---|---|
| 浏览器工作台、导入与元信息核对 | 已实现，实际 API 驱动 |
| 持久化任务、幂等、取消/重试、重启恢复 | 已实现，单有界 spawn 执行器 |
| 演示情绪输出、缺失证据与人工复核 | 固定合成输入和契约示例，实际流程已验证 |

| 预处理、特征提取、统计、分类训练评估、通用图表 | 保留旧研究入口，修复 IO/UI 边界；未宣称全部 Web 迁移 |
| AI 文字助手 | 独立可选，默认关闭，实际本机模型未验证；取消/历史竞态用测试 HTTP 替身验证 |

## 验证限制

- 35 个算法源码和一个既有输出工件字节哈希保持冻结；固定合成输入的 20 个 EEG 特征值与原源码一致。没有重训，没有对真实权重的情绪推理或心理疾病判定进行验证。
- 新前端验证包含指定桌面像素尺寸、1024 宽、等效 125%/150% 缩放截图和 axe AA 自动检查。没有改动 Windows 全局 DPI；原生系统缩放的全部应用组合与辅助技术人工审计未完成，不能等同于已获得无障碍认证。
- 旧主入口隐藏烟测可确认五面板初始化与共享状态；可见 Qt 子图的全部交互、所有科研计算参数、硬件链路及高 DPI 尚未全面验收。
- Python 虚拟环境依赖本机解释器路径。新交付或换电脑时按锁文件重建。
- SQLite/本地工件未提供多用户权限、磁盘加密或公网认证。当前只监听回环；研究/服务视角属于界面视角。
- 没有声称完成性能压力测试、渗透测试、临床验证或真实个体准确率验证。

更细的源码与科学契约证据见 `capability-audit.md`；旧入口修复与审查见对应 legacy 报告。
